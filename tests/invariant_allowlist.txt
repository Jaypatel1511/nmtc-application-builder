#   SOURCED  statutory or published constant carrying its citation in-line
#   TOOL     a statement about this tool, not about the CDE
#   FORMAT   scaffolding with no propositional content
#   DERIVED  a fixed sentence FRAME whose every figure is computed from the
#            CDE's own inputs. New in this revision, and the reason the list
#            grew: under byte-identity these lines never appeared, because the
#            interpolated value made every scenario differ.
#
# WHY THIS FILE GREW FROM 116 TO 172 ENTRIES
#
# The gate used to intersect RAW lines, so interpolating any CDE value into a
# sentence hid the sentence from it. Four blockers lived in that gap at once,
# including
#
#     f"All {total_projects} projects have completed preliminary underwriting
#      review."
#
# — invariant in substance, variable in bytes, invisible for six rounds. The
# gate now masks interpolated values (see _mask in test_invariant_output.py)
# before intersecting, so a sentence that says the same thing with different
# nouns is recognised as the same sentence. The 56 lines that appeared as a
# result are not new output; they are output that was always there and never
# had to be justified.
#
# READING THIS FILE IS THE HIGHEST-VALUE REVIEW ON THIS PACKAGE. Every line
# below is something the tool says to the CDFI Fund about every CDE that ever
# runs it. If a line here is not defensible for ALL of them, it is a defect.
#
# DERIVED IS NOT A RUBBER STAMP. It means: the frame is fixed, and the numbers
# in it come from the CDE. If a DERIVED frame ever describes its numbers as
# something they are not — a threshold as a percentile, a partial denominator
# as a whole one — it is the same defect class this gate exists to catch, and
# the category will not save it.
#
