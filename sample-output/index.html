Fictional data — and the package did not stop this page making it

The CDE in these documents — Riverbend Community Capital CDE, LLC — does not exist, and neither do its projects, addresses or figures.

These files were produced by calling CDEProfile.sample() and then Application.generate(), which is the path this page's own build takes. The package does not refuse that path. The refusal in nmtcapp/core/sample_identity.py sits on the two places where an identity you supply is read: CDEProfile.from_yaml(), which raises unless it is passed allow_sample=True — and so nmtcapp analyze --cde refuses this identity too — and the Streamlit CDE Profile upload. Neither CDEProfile.sample() nor Application.generate() checks anything, so a script that starts from the sample profile produces documents like these without objection. Do not file them.

Note how much of the document is [CDE TO COMPLETE: ...]. That is the point: this tool assembles and computes what it can derive from your own inputs, and marks everything else as yours to write.
